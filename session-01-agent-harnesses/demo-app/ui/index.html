      SESSION 1
      
          
      Explore the harness
      
        
      
        
      
      
      
      
        
      
        
      
          
      
          
      
            
      Who chooses the steps?
      
            
      
              The agent can choose tools, or the application can fetch HN
              metadata before asking for a briefing.
            
      
            
          
      
          
      
            
      What starts the work?
      
            
      
              Ask from the task, or schedule one request using the current draft
              and next-briefing settings.
            
      
            
      
              
            
      
            
      
            
      
              Scheduling requires this active workshop visit. It ends with the
              visit.
            
      
          
      
          
      
            
      Who permits a write?
      
            
      
              user-preferences writes pass a permission check before execution.
              Approval shows the exact proposed change.
            
      
            
          
      
          
      
            
      How long does work continue?
      
            
      
              Requests and tool work continue within the active visit. Stop ends
              current work. Reconnecting reads the same execution.
            
      
            
      
            
          
      
          
      
            
      What can the agent use?
      
            
      
              HN metadata, the local briefing skill and your visitor
              user-preferences. Article text and a browser tool are unavailable.
            
      
            
      
              
            
      
          
      
          
      
            
      Who reviews the result?
      
            
      
              An optional reviewer receives its own context after the producer
              finishes. Both share the briefing's attempt allowance.
            
      
            
          
      
          
      
            
      What carries forward?
      
            
      
              Conversation stays in this running app. Saved interests and links
              survive visits.
